# 智慧上傳元件

本目錄包含產品相關的智慧上傳元件：

## 元件結構

### `SmartImageUploader.tsx`
- 主要的智慧上傳元件
- 整合拖拽上傳介面
- 本地預覽展示
- 批量選擇功能

### `UploadProgressIndicator.tsx`
- 上傳進度顯示元件
- 即時狀態更新
- 錯誤狀態處理

### `PreviewGallery.tsx`
- 本地預覽圖片展示
- 圖片排序功能
- 刪除和編輯操作

### `UploadQueue.tsx`
- 上傳佇列管理界面
- 暫停/恢復控制
- 批量操作支援

## 設計原則

- 響應式設計
- 無障礙支援
- 效能最佳化
- 使用者體驗優先
- 與現有 UI 系統整合
